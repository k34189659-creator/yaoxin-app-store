# 瑤芯漫畫翻譯器 0.5.3（versionCode 15）

本輪只集中修正 0.5.2 英文漫畫譯圖的視覺問題，保留 0.5.2 的語言選擇狀態及提示列 UI。

## 英文翻譯修正

1. **英文字行遮罩與氣泡分開**：新 `EnglishInkMask` 僅使用 ML Kit Latin OCR 確認的英文字行，NCNN 遮罩僅在字行內做輔助；不再直接將 NCNN 對人物、氣泡輪廓的其他偵測結果算入擦字。
2. **控制擦字膨脹**：英文使用 `maskDilate=6`（半徑 3px）、`bboxPad=4`，不使用日文 0.2.0 對漢字／假名白邊的膨脹參數（預設半徑 12px）。日文仍原參數。
3. **避免跨氣泡合併**：`EnglishBubbleBoundary` 偵測同列 English OCR 行間明顯的深色水平分隔線；存在分隔線時，英文分組器不得跨線連結。
4. **彩色背景局部修補**：在 0.2.0 擦字後，對周圍背景色一致的英文文字筆畫再做小區域顏色修補；若鄰域顏色分散、疑似人物／複雜紋理，則保留 AOT 的結果而不強制塗成單色。
5. **英文專用安全試排**：依實際中文字形寬度重新換行，自動縮字到 6px，限制文字不得超出擴充後的原文區域；中文的排版區域和擦字遮罩分開計算。
6. **統一入口**：正式翻譯／自測／手動重排／局部補救使用相同英文特例，而非一條使用 LegacyRenderer、另一條使用新版 SmartRenderer。
7. **降低 GC**：逐像素背景補色採固定大小陣列，減少臨時物件分配；重排版前釋放舊版完整渲染圖。

## 測試

- 合成測試：英文行分組、分隔線分組、僅在字行範圍建立遮罩、局部背景補色、英文安全試排 API：通過。
- 原始碼差異與 ZIP 完整性：待打包檢查。
- **Android Gradle assembleDebug、實機 NCNN AOT、英文漫畫效果：本環境未執行，需小蘭編譯及使用者驗收。**

### 實機驗收建議

使用與 0.5.2 相同的英文漫畫三頁逐張比對：
1. 氣泡黑色邊框與人物線條是否不再被抹除；
2. 彩色／漸層聊天氣泡是否減少大面積灰、綠補色斑；
3. 長句是否在框內重新換行縮小，且沒有遮蓋鄰近氣泡；
4. 多語言切換、框選翻譯、模型/API、佇列及原有日文漫畫功能是否正常。

這輪尚未證實所有頁面均能正確判斷氣泡邊界，也未聲稱完全解決複雜插畫背景的修補問題。
