# 瑤芯漫畫翻譯器 0.5.1（versionCode 13）

此版從 0.5.0 **完整原始碼**修改，保留 0.4.1 繼承的日文 0.2.0 翻譯核心、漫畫庫與多本佇列資料格式。

## 修改內容

1. 英文 OCR 專用管線：Google ML Kit Latin 提取英文行與座標；英文獨立 `EnglishDialogueGrouping` 根據水平重疊、字高、行距重建區域，並使用英語漫畫左到右的對話框閱讀順序。區域內文字拼成完整句子。
2. 翻譯同頁所有英文對話框時，沿用既有 `LlmTranslator` 的 `<|ID|>` 一頁多區對應方案，使用專案既有的英→繁體中文配置，避免多行分別翻譯導致語意不連貫。
3. 英文後段不再使用 0.4.x 現代 `SmartTranslator`，改使用 `Legacy020SmartTranslator.runWithAnalysis` 的成熟翻譯、擦字與嵌字流程。**日文仍由原本的 analyze/run 進入，不替換日文 OCR／分組演算法。**
4. 正式翻譯、本機自測、頁面診斷與局部框選補救改採一致的英文 OCR／0.2.0 後段。框選模式有可見的粉紅邊框、拖曳選取遮罩與選取完成標記。
5. 設定頁精簡：API Key 設定／更換與連線測試、模型是否已下載（未就緒時可下載/補齊）、單本/多本自動匯出與目標資料夾。移除 API provider/model ID 欄位、模型詳細檔案列表、SHA-256 按鈕、刪除模型及關於/技術文字在 UI 的展示；**後端設定、LICENSE/NOTICE 不刪除**。
6. 主頁的選取專案模式新增可見數量與勾選說明。

## 真機驗收重點

- 請使用**相同英文漫畫**，分別對照 0.5.0 的英文模式與 0.5.1：多行對話是否合併、是否不跨氣泡混併、英譯繁中是否可讀；以及擦字/嵌字是否仍準確。
- 英文不規則藝術字、斜排氣泡及兩個氣泡緊貼的案例可能仍需手動框選補救；本輪為幾何分組，**不是完整的氣泡邊界視覺模型**。
- 日文 0.2.0 的品質回歸：使用同一張日文圖比較翻譯結果、擦字、嵌字，確認未受英文改動影響。
- 測試英語框選時不會讀成日文，且在螢幕上能清楚看到粉色操作邊框及拖曳選區。
- 設定更換 API Key、測試連線、模型未下載/已就緒、匯出資料夾與單本/多本自動匯出開關。
- 測試既有專案與翻譯佇列資料保留，不能因升級清除資料。

## 編譯與測試

Android 原始碼在此環境無 Android SDK，未執行 `assembleDebug` 和 `testDebugUnitTest`，由小蘭在 PC 編譯：

```
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

這裡額外使用 `kotlinc` 在 JVM 獨立執行英文對話框分組的 3 項斷言，皆通過。對完整 Kotlin 檔只進行無 SDK 的語法檢查，不能取代 Android 編譯。不要直接上架。
