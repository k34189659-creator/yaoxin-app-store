# 瑤芯漫畫翻譯 0.5.5 (versionCode 17) — 英文四類分流第一輪實驗

基礎：0.5.4 完整原始碼。這是供小蘭編譯、由使用者測試的源碼實驗版；並非已驗收的 APK。

## 這輪已完成

- **英文四類分流路由**：普通框內、無框圖上、彩色框內、特殊彩字圖上。先在原圖完成 OCR → 英文行分組 → 分型，僅對應文字行建立擦字遮罩，**不把整本漫畫依四類重跑四次**，也不重新 OCR 已嵌入中文的圖。
- **分型後採不同策略**：框內可在高確信背景平滑時局部補色，圖上文字一律不使用整片背景補色；不同類型的掩膜取捨、排版框擴張、描邊規則分開設定。
- **英文擦字稽核**：檢查原文遮罩像素是否確實改變；沒有確認有效擦除的文字行恢復原圖、跳過中文嵌字並標記部分／失敗，避免英文與中文疊字。
- **手動重排與局部修補**採用同一套分型／遮罩規則。
- **每區診斷**保留類型、擦字是否可靠、版面超框及其備註；頁面依翻譯與擦字、排版結果區分成功、部分、失敗。
- **降低英文擦字外擴幅度**：6→3 px/單位（沿用舊模型，減少破壞氣泡邊緣）。
- 日文仍沿用既有 0.2.0 核心；未調整日文 OCR、翻譯提示、擦字、嵌字或模型。

## 模型選擇

第一輪**不下載額外模型**。英文字辨識使用既有 Google ML Kit Latin，背景修補使用已經安裝的 NCNN AOT-GAN 及原有局部修補方法。不同類型已可設定不同掩膜與渲染策略；這是可擴充分流的第一個可測試版本，**尚非四套獨立訓練的 OCR 模型**。這能先排除分類／資料流與擦字問題，確認效果後再考慮只為效果字引入額外模型。

## 本輪限制與後續重點

- 第一輪用背景顏色、紋理、文字色彩等啟發式分類，沒有專門的氣泡邊界神經網路；特殊藝術字的分型可能出錯。
- 稽核目前判斷掩膜像素是否發生實質擦除，**不是二次 OCR 證明完全無英文殘留**；某些小字/特殊字仍可能標記部分完成。
- 與 0.5.4 相比，多了分類和抽樣稽核，需實測手機效能；不會同時載入四個額外模型。
- 英文視覺最後處理仍沿用現有 `EnglishVisualFinish` 的骨架；使用不同類型的獨立策略，而非完全重寫四套 AI。
- 翻譯 API、分組及日文核心未改；有些英文特殊字仍需人工修正。

## 建置與驗收

小蘭在 Android SDK 35 / Kotlin / Gradle 環境：`./gradlew :app:assembleDebug :app:testDebugUnitTest`。沿用現有套件名與正式簽章。不要再手動回填舊版英文 `EnglishVisualFinish`；來源已包含需要的類型／遮罩／稽核檔案。

在同一本英文漫畫固定三類頁面比較：普通氣泡、彩色聊天氣泡、無框藝術字。檢查殘留英文、疊字、背景色塊、中文字超框、分類診斷和成功／部分／失敗計數。再用同一本日文漫畫確認沒有退化。

**本環境沒有 Android SDK**：已完成 Kotlin 核心 stubs 編譯（不等於 Android 完整編譯）、純 Kotlin 五類合成分類測試和 ZIP 完整性檢查。真機速度與圖像品質未實測，必須由小蘭與使用者驗證。
