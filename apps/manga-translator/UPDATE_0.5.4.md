# 瑤芯漫畫翻譯器 0.5.4（versionCode 16）

本版只針對 **英文漫畫** 譯圖「像貼字、彩色背景有補色斑」做局部改善，保留 0.5.3 的 UI、翻譯排隊、日英選擇與已有功能。

## 改動

1. 英文筆畫遮罩：當單個 OCR 行框跨不同顏色背景時，不再根據單一背景亮度把整片有色背景當作黑字；僅信任限定區域的偵測筆畫，並排除超大連通斑塊。
2. 英文背景補色：改由 `EnglishBackgroundModel` 對未遮罩的原圖像素建立**區域共用的純色／漸層估計**，替代舊版逐像素隨機色塊式修補。只對高一致性的背景套用，遇複雜插畫、網點或多色背景就**保留 0.2.0/AOT 原有修補結果**。補色範圍對齊英文擦字遮罩 3px 膨脹。
3. 英文中文字體：依原 OCR 行高限制字級上限，降低貼字忽大忽小；平滑的白色／彩色氣泡不再加白色粗邊，只有複雜背景才補細描邊。仍會自動換行與縮字。
4. 新增 `EnglishBackgroundModelTest`，覆蓋純色、漸層、多色複雜背景三個案例。

## 明確不修改

- 日文 0.2.0 OCR／分組／翻譯／擦字／嵌字核心檔案與參數；
- 英文 Venice API 翻譯提示詞與分組；
- 0.5.3 UI、專案、佇列、API Key、匯出設定。

## 檢查結果與限制

- 純 Kotlin 背景重建三組合成測試通過。
- `EnglishVisualFinish`、`EnglishInkMask`、`EnglishBackgroundModel` 在 Android API stub 下 Kotlin 編譯通過。
- Android Gradle 全專案建置、真機 AOT、真實漫畫畫質改善仍需編譯和實機驗收；本版未宣稱這些已通過。
- 不規則氣泡邊緣、極端複雜彩色插畫的修補品質仍可能需要局部人工調整。
