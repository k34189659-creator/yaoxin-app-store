# 實機驗收步驟（給使用者）— 0.2.0

> 助手無法在此裝置安裝 APK（DSHA 命令政策禁止 `pm install`），以下步驟需由使用者手動執行。
> 每一步都請記錄「通過／失敗＋錯誤訊息」，失敗時不要略過。

## 前置
1. 從 `/sdcard/Download/yaoxin-manga-0.1.0-debug.apk` 或交付的 `dist/` 安裝。
   - 檔案管理器需有「安裝未知應用程式」權限。
2. 開啟 App，允許網路。
3. 確認裝置為 arm64（本 APK 只含 `arm64-v8a`）。

## A. 模型
1. 設定 → 翻譯模型 →「下載模型（約 248 MB）」。
2. 檢查：進度條、檔名、總大小、完成後「SHA-256 已完整驗證」。
3. 按「驗證」再跑一次，應顯示「模型完整，SHA-256 全部正確」。
4. 失敗時記錄是哪個檔、HTTP 狀態、可用空間。

## B. API
1. 設定 → API Key → 貼上 Venice Key → 儲存；重開 App 後應仍顯示「已安全儲存」。
2. 「取得模型清單」：應列出模型；`uncensored` 模型置頂；選 `venice-uncensored-1-2`。
3. 「測試連線」：應顯示 HTTP 200、延遲、token、費用（若有）。
4. 故意貼錯 Key → 測試應顯示 401，且訊息不含完整 Key。
5. 自訂端點（可選）：填一個 OpenAI 相容 base URL，重複 2–3。

## C. 本機引擎自測（不需要 API）
1. 設定 → 進階 → 本機引擎自測 → 選一張日文漫畫頁。
2. 預期：左邊原圖、右邊中文嵌字（內容是「這是模擬翻譯…」固定句）。
3. 檢查：文字沒有超出對話框、直排/橫排方向合理、描邊可見。
4. 記錄 stats 的偵測/OCR/擦字/排版毫秒數。
5. 若失敗：記錄錯誤、頁面尺寸、機型。

## D. ZIP 匯入與頁序
1. 準備 ZIP：`ch1/1.jpg, ch1/2.jpg, ch1/3.jpg, ch1/10.jpg`，加上中文資料夾 `第2話/1.jpg` 與 `說明.txt`。
2. 首頁 → 選擇 ZIP → 匯入。
3. 檢查頁數、縮圖順序（1,2,3,10；ch1 在 ch2 前）、中文檔名顯示正常。
4. 檢查「說明.txt」沒有變成頁面。
5. 惡意測試（可選）：含 `../evil.jpg` 的 ZIP 應被拒絕，且不會在專案外產生檔案。

## E. 翻譯／暫停／續傳
1. 設定好 API，頁面清單 → 開始翻譯。
2. 翻譯 2–3 頁後按暫停；確認狀態「已暫停」、進度保存。
3. 強制關閉 App → 重開 → 開啟專案 → 應可「繼續翻譯」，已完成頁不重做。
4. 檢查每次 API 錯誤都出現在「錯誤與重試紀錄」，失敗頁顯示原因。
5. 429/斷網測試（可選）：翻譯中開飛航模式，應重試後標記失敗、保留原圖。

## F. 預覽與手動修正
1. 點已完成頁 → 切換「原文／繁體中文」，確認圖片正確。
2. 編輯譯文 → 改一個對話框 → 儲存並重新嵌字。
3. 確認：不用等待 API（瞬間完成）、文字位置/大小合理、只改該區。
4. 局部重新辨識 → 原文更新，頁面回到待翻（不呼叫 API）。

## G. 匯出
1. 匯出 → 選新檔名（例如 `book_繁中.zip`）。
2. 用檔案管理器解開：
   - 資料夾/檔名與原始 ZIP 相同（含中文）。
   - 已完成頁是繁中；失敗/略過頁與原圖位元組相同。
   - `說明.txt` 仍在。
3. 確認原始 ZIP 沒有被修改（大小/修改時間）。
4. 用漫畫閱讀器開啟輸出 ZIP，確認頁序正確。

## I. 診斷（0.2.0 新增）
1. 完成一頁翻譯或失敗頁 → 單頁檢視 → 右上「診斷」。
2. 切換：原圖／偵測框／OCR 原文／API 譯文／擦字遮罩／擦字後／最終嵌字。
3. 檢查框與文字是否對齊（同一頁、同一座標；預覽縮放不應錯位）。
4. 按「擦字預覽」：不呼叫 API，確認白泡邊框沒有被塗掉、複雜區線條還在。
5. 按「漏字檢查」：只標記疑似未覆蓋日文；確認沒有自動擦除。
6. 匯出報告：先不勾文字/圖片，確認 JSON 沒有 API Key；再勾選一次，確認包含原文/譯文/預覽圖。
7. 把報告（必要時含圖）回報；這是後續修復的依據。

## J. 部分完成頁（PARTIAL）
1. 找一頁有狀聲詞/單字/模型易拒的頁面翻譯。
2. 預期：成功對話框變繁中；失敗區保留日文；頁面標記「部分/待檢查」，不是整頁日文。
3. 匯出後確認該頁是「部分繁中 + 部分原文」，不是整頁原圖。
4. 若你希望失敗頁整頁保留原圖，記錄頁碼；目前 0.2.0 固定採 PARTIAL。

## K. 局部框選補救（0.2.0 新增）
1. 單頁檢視 →「框選補救」→ 在漏譯文字外拖一個框。
2. 預期：只處理該框，OCR→翻譯→擦字→嵌字；其他頁面/對話框不變。
3. 若 OCR 讀不到，輸入日文原文 → 翻譯並嵌字。
4. 開「補救紀錄」：單獨按「重新辨識」「重新翻譯」「重新嵌字」；只有重新翻譯應呼叫 API。
5. 匯出 ZIP，確認補救區已包含在該頁譯圖。

## L. 智慧擦字與排版（0.2.0）
1. 設定 → 擦字方式：智慧（預設）→ 白泡頁檢查是否只清字、不塗整框。
2. 換成「全部 AI」與「快速擦字」各跑一頁，比較殘留/模糊/速度。
3. 編輯譯文 → 位置 ←→↑↓、字級 A−/A+、方向（直/橫/自動）→ 儲存並重新嵌字（不呼叫 API）。
4. 找長句/小框：預期標記「排版待處理」，不得只顯示半句；必要時手動調整。
5. 找短句：預期字級不要被縮到很小。

## H. 記憶體／品質
1. 選一本 ≥100 頁、其中 1–2 頁 ≥4000px 的漫畫。
2. 翻譯期間觀察是否 OOM/閃退；完成後檢查大頁解析度不變。
3. 比較 JPEG 原圖與譯圖的線條（壓縮品質 95）；若明顯變差記錄頁碼。
