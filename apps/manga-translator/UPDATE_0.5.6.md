# 瑤芯漫畫翻譯 0.5.6

版本：`0.5.6`，versionCode：`18`。基準：使用者交付的完整 `0.5.5` 原始碼。

## 這一輪修正什麼

使用者回報四類現象：白色對話框邊線出現黑楔形／糊邊、圖上文字後方出現矩形色帶、彩色聊天泡泡缺角，以及一頁只完成 1／8 區卻有極長密集文字柱。畫面顯示的 34,351 tokens 是用量合計，不能單憑截圖認定全部是可見輸出。

原始碼中確認的主要問題：英文四類標籤後仍呼叫 `Legacy020SmartTranslator.runWithAnalysis`，先共用舊擦字和舊排版，再重做一次英文排版；翻譯器未限制完成輸出且未處理截斷原因；英文排版會外擴 OCR 框，文字放不下仍繪製；失敗還原的矩形範圍與實際膨脹遮罩不同。

0.5.6 將英文主流程獨立出來，所有區域以同一張原圖辨識／分類，依序修補，最後才畫中文。正式翻譯、手動重繪、框選補救及擦字預覽使用相同英文圖像處理入口。

## 翻譯回應與費用控制

- 每頁依原文字數／區域數設定 512～4,096 completion tokens 上限，包含供應商計入的 reasoning tokens。這是輸出預算，不是整頁輸入＋輸出的總用量上限。
- 檢查正常結束原因、區域 ID 缺失／重複／未知 ID、異常字數、循環重複、混入分析或未標記說明等。
- 達到輸出上限的截斷回應不作為完整譯文。無效區不擦、不畫、不寫入成功翻譯快取；有有效對應的其他區仍可處理。
- 不截斷異常長文來勉強塞進圖片。內容、格式和長度失敗不自動重試；英文只有暫時性 HTTP／網路錯誤才依既有重試設定處理。
- 重新使用舊快取前再次驗證，並保留有效譯文供重做擦字時使用。
- Venice 英文請求在既有 `thinking=false` 下明確關閉思考；可選參數協商不會移除輸出上限。

參數依據：[Venice Chat Completions 官方文件](https://docs.venice.ai/api-reference/endpoint/chat/completions)。沒有以使用者 API Key 執行付費翻譯。

## 氣泡、遮罩與背景

- 只有原圖中找到封閉的連通背景，才把區域視為有框氣泡。單純一片平色不再等同於氣泡。
- 保留 ML Kit 的四角座標；遮罩依原字形建立，不把文字矩形整塊當作可擦範圍。短句不因字數少而直接被過濾。
- 即使 detector 只標到一截邊框，也會沿原圖色彩輪廓檢查是否延伸到文字支援範圍外，避免把截短的邊線當成字。
- 普通與彩色氣泡僅在封閉背景能通過平滑色面檢查時補色；紋理、無框圖上文字使用現有 AOT 模型局部修補，且沒有英文失敗時的平塗回退。
- 模型結果只提交到核准的筆畫遮罩，遮罩外像素保持原值。即使模型改變整個裁切圖，也不會把整塊結果貼回頁面。
- 掩膜所有權與排版範圍檢查包含相鄰失敗區，避免一區成功卻改壞應保留的另一區。
- 擦字變化檢查後，正式流程還會在未填中文字的圖上跑一次 Latin OCR；仍辨識到相同原英文的區域會還原完整編輯遮罩。這不是語意／畫質的完整自動驗收。

四類仍共用既有 ML Kit Latin 與 AOT 模型；本次沒有新增或更換模型，也沒有把四個不同 OCR 模型說成已實作。幾何判斷、遮罩、修補和排版的共同元件可重用，各類進入對應分支依序處理。

## 排版與狀態

- 先以實際字型度量試排，確認放得下才擦字。安全範圍來自封閉背景中的內接矩形；無可靠邊界時使用原 OCR 範圍，不任意向外擴張。
- 最低 8 px 仍無法容納、文字量異常、或與鄰區範圍衝突時，保留原區並記錄原因。文字比例在試排前套用，不再先判定容納後才放大。
- 框內不加白色描邊；圖上文字描邊變細。換行處理中文標點及拉丁詞，避免字形跑出安全範圍。
- 最終成功數以真正完成繪製的區域計算；若等待修補／OCR 期間譯文變更使舊排版失效，原文字會恢復，不會留下空白卻顯示成功。
- 框選補救失敗會顯示原因，不再回傳原圖後宣稱補救成功。
- 舊版框選補救圖片保留檔案及原文／譯文資料，但不直接疊回新的結果。需在補救清單重做擦字／嵌字，成功後才標記新版修補版本。舊快取中的正常譯文仍可重用。

## 仍需用原漫畫確認的部分

本次收到的是處理後截圖，沒有這四個位置的原始漫畫頁與當次 API 原回應，因此不能從截圖重做真正的前後對照。

封閉背景判斷仍是影像演算法，沒有新增訓練過的氣泡分割模型。大而空的氣泡、開口邊界、複雜紋理或字與圖案相連時，可能保留原區並標記未完成。殘留 OCR 也可能漏掉破碎筆畫。這些情況需要原頁實機結果與中間遮罩才能繼續調整。

建議先重跑此次出問題的幾頁，觀察邊線／泡泡顏色是否完整、譯文是否留在框內、短句是否仍漏譯，以及失敗區的原因。成功／部分完成／失敗不代表每句譯文語意均已人工審核。

日文 `Legacy020SmartTranslator.kt`、`Legacy020Inpainter.kt`、`Legacy020SmartRenderer.kt` 與 0.5.5 基準逐檔比對保持相同；不將本輪英文策略套入日文。
