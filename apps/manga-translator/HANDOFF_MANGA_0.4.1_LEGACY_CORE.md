# 瑤芯漫畫翻譯器 v0.4.1 — 翻譯核心回退 0.2.0（保留新版櫻花 UI）

## 核心改動

- **日文 → 繁體中文**：正式翻譯恢復 0.2.0 的 NCNN 偵測、OCR、局部及切片補抓、原本分群、翻譯/快取/狀態判定、0.2.0 提示詞與 few-shot，以及原始智慧擦字/嵌字排版。具體來源為使用者上傳的 `yaoxin-manga-0.2.0-source.zip`。
- **英文 → 繁體中文**：仍使用 0.4.0 的 ML Kit 英文 OCR、英文閱讀順序、英文提示詞與新排版流程，因為 0.2.0 未提供完整的英文辨識模式。
- **UI／資料不倒退**：完整保留 0.4.0 首頁、設定、翻譯進度、編輯、匯出、品牌圖片及專案保存架構；已存在的 0.4.0 可用功能不會因回退被大量刪除。
- **自測與診斷**：同樣依目前作品語言選用相應核心；日文自測與診斷也走 0.2.0，以免和正式翻譯結果不一致。
- **手動修正後重新擦字／嵌字**：日文也會沿用 0.2.0 的舊式擦字與排版，避免第一次和手動修改重繪使用兩套不同算法。
- **API 設定**：沿用 0.4.0 的 Venice / OpenAI 相容端點、金鑰儲存與匯出等管理功能，不把舊版整個 App 複製覆蓋。
- **原始碼審核**：舊 SmartTranslator、Inpainter、SmartRenderer 保留原演算法，只修改類別名稱、與現存的資料型別相容（0.4.0 新增的欄位已有預設值），因此同時可保留英文新版流程。

## 小蘭建置／驗證

1. 專案解壓縮後以 `yaoxin-manga/` 為根目錄，在已有 SDK 35 / Gradle / JDK 的 PC 執行 `./gradlew :app:assembleDebug :app:testDebugUnitTest`，必要時執行 `:app:lintDebug`。
2. 本版指定 `versionName=0.4.1`、`versionCode=8`、`applicationId=tw.dafeiyu.mangatranslator`；使用既有 release 簽章，避免 Android 不能覆蓋安裝。
3. 測試同一本日文漫畫同幾頁，**實機直接比較 0.2.0 與 0.4.1**：OCR 文字區、全文覆蓋率、翻譯自然度、擦字背景、中文溢出、處理耗時；畫質不是用純 Kotlin 測試能驗證的。
4. 測試用既有 API Key 的正式 Venice API／相容端點（或以測試模式先自測；不要將金鑰印到日誌）。
5. 再測英文作品翻譯、從匯入 ZIP/CBZ 到編輯/預覽/匯出、舊專案快取、暫停恢復、真機記憶體佔用、深淺主題。

## 本次環境實際驗證

- 原始 0.2.0 ZIP：**152 個項目、zipfile 完整性通過**。
- 比對 0.2.0 和 0.4.0 的原始碼差異，確認新版與舊版確實在 OCR、翻譯規則、擦字、排版上不同。
- 核對 0.4.0 舊 UI、主題和英文現代版 SmartTranslator 的檔案位元組保持不變；日文新接點存在。
- 進行 Kotlin 原始碼語法層掃描；由於此環境缺 Android SDK／Gradle 和 Android 相依函式庫，**沒有 Android 編譯／完整單元測試或實機翻譯結果**。不能宣稱品質已恢復成功，必須以實測證實。

## 注意

- 新版本的日文 OCR 設定頁仍保留 0.4.0 的 PP-OCRv6 下載及模式選項，但 **日文優先走 0.2.0 NCNN 原始管線，不會因已下載 PP-OCRv6 就改走新式融合偵測**；這是刻意為恢復原本表現。英文仍獨立。
- 0.2.0 原始背景修補及排版的已知限制（例如少數有色背景、框內溢出）也可能一同回來；本次不是宣稱修好所有畫質問題，而是優先回復使用者明確偏好的版本。
- 針對已有翻譯快取，重跑可能仍使用快取。若要比較同幾頁真正的翻譯文字，請建立獨立新專案、避免直接沿用之前版本的翻譯快取導致結果混淆。
- 本次不涉及自動裁剪器的影片連結功能；兩個 App 分開開發。
